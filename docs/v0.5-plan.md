# v0.5 — Image Gallery / Browser — Plan (stub)

Status: **STUB** — to be fleshed out once v0.4 ships.  Captured
2026-05-28 so the v0.4 data model is designed with v0.5 in mind.

---

## Theme

A first-class image browser inside the app for the RX folder and TX
history.  Today users have to open Finder / Explorer to browse
received images.  After v0.4 each image will be linked to a QSO
record, so the gallery can group and filter by callsign.

## Why after v0.4, not before

Gallery items naturally key off QSO records.  Building gallery first
means retrofitting QSO links later.  Logbook is the foundation;
gallery is the visualization layer on top.

## Initial sketch (subject to revision)

### UI surface

- New window (or tab in Logbook window — TBD) opened via Tools →
  Gallery… or Cmd/Ctrl+G.
- `QListView` in `IconMode` with thumbnails.
- Group / sort options:
  - By date (default)
  - By callsign (uses v0.4 QSO link)
  - By mode (Martin, Scottie, PD, etc.)
- Click → full-size preview pane with metadata sidebar:
  - Decoded mode
  - Frequency at completion
  - Time
  - Linked QSO from v0.4 (one-click → opens the QSO row in Logbook)

### Operations

- Delete (image file + remove from QSO record if linked)
- Export (copy to user-chosen location)
- "Re-send" — load the image into the TX panel as a new outgoing
  transmission.  Useful for replying to a CQ with the same image
  you sent before.
- Tag / star (optional; nice-to-have)

### Search

- Callsign substring
- Date range
- Mode
- Free-text search across linked QSO notes

## Sources

- TX history dir (new in v0.5 — today TX images are user-supplied
  and not retained by the app)
- `images_save_dir` (RX, populated since v0.3.x)
- Any image referenced by a QSO row that still exists on disk

~5–7 days once v0.4 patterns are established.
