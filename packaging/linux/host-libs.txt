# Libraries the Linux bundle must NOT contain: the host's copies are used.
#
# One soname prefix per line.  Read by BOTH open_sstv.spec (which strips them
# from the bundle) and the Linux smoke test in .github/workflows/build.yml
# (which fails the release if any made it in).  Keeping one list is the
# point: the spec and the test each had their own copy once, and a
# hand-kept duplicate is how this project has shipped wrong numbers before.
#
# Source: the AppImage project's excludelist,
# https://github.com/AppImageCommunity/pkg2appimage/blob/master/excludelist
# (the entries that can end up in a PyInstaller + PySide6 bundle).  The
# common reason is that another host library loaded into the same process
# was built against the host's copy.  A bundled older copy then fails with
# "undefined symbol" or "GLIBCXX_... not found" errors.  That risk grew when
# the Linux build moved to AlmaLinux 8, whose libraries are old on purpose
# (for the glibc 2.28 floor).

# Audio: bundled ALSA can't see the host's PipeWire/PulseAudio plugins;
# libjack must match the host's JACK server.
libasound.so
libjack.so

# Graphics: the host's GPU driver brings its own copies of all of these.
libGL.so
libEGL.so
libGLX.so
libGLdispatch.so
libOpenGL.so
libdrm.so
libgbm.so
libxcb.so
libxcb-dri2.so
libxcb-dri3.so
libX11.so
libX11-xcb.so
libwayland-client.so

# Fonts and text: must match the host's font configuration.
libfontconfig.so
libfreetype.so
libharfbuzz.so
libfribidi.so

# C++ runtime and base libraries: host GPU drivers (Mesa's LLVM in
# particular) need the host's newer copies.
libstdc++.so
libgcc_s.so
libz.so
libexpat.so
libuuid.so
libcom_err.so
libgpg-error.so
